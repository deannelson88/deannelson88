### About me

I lead the front end of a B2B SaaS reporting platform used by large organisations. I joined when I was close to the only front-end developer, built most of the React app, and now set its architecture, conventions, tooling and review standards. I also work full-stack in the platform's .NET API.

Before that I spent three years at a software consultancy building applications for corporate clients, and I've done freelance work for local businesses since 2017.

> Most of my work lives in private company repositories, so the activity on this profile is only my own projects.

### What I focus on

- **Front-end architecture:** keeping a large React codebase modern while it keeps shipping. I've taken one through Webpack to Vite, JavaScript to TypeScript, Redux to RTK Query with Zod, and MUI to Tailwind, without a feature freeze.
- **Design systems and accessibility:** shared component libraries, design tokens with brand and dark-mode theming, and accessible primitives built to WCAG 2.2 AA.
- **Quality and developer experience:** CI smoke tests, lint and type gates, per-ticket Docker environments, and fast, thorough code review.
- **AI-assisted engineering:** team workflows with Claude Code, including shared rules, skills, review agents and guard hooks that keep output consistent.
- **Products for non-technical users:** plain language, one clear primary action, and behaviour people can rely on.
